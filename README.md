# Vitest examples

## Included Tests

- Counter
- Greeting
- Users
- Longest String
- Positive or Negative
- Prime Number
- Shipping Cost
- Sum

## Testing with Vitest

Run tests

```bash
npm run test
```

Run tests with coverage

```bash
npx vitest run --coverage
```

Run tests in the Vitest UI

```bash
npx vitest --ui
```
